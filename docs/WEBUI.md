# WebUI 使用说明

在 WSL 项目目录运行：

```bash
make webui
# 可选：make webui ARGS="--port 8000"
```

打开本机 `http://127.0.0.1:7860`。Gradio 为可选依赖，`make webui` 按需安装 webui 组。
输出根沿用 `R2048_OUTPUT_DIR`，默认项目 `output/`。

## 对局工作区

模型连接、对局分析、局面编辑和棋谱复盘均在此处。实验任务计算期间新推理和连接暂停；
编辑预览及复盘可以使用。结束后保留当前棋盘，继续使用原对局模型。

## 实验工作台

1. 在跑谱、双头训练、评测与评分或完整迭代页设置本次操作。每页独立保存参数，训练配方
   和训练设置只出现在双头训练、完整迭代页。高级设置默认折叠。
2. 点击“检查…配置”阅读中文摘要。修改参数或切换页面后，旧摘要失效，必须重新检查。
3. 点击“确认并加入后台队列”。重复确认同一摘要不会创建第二个任务。
4. 点击“查看任务进度”，或切换到独立的“任务”页。任务页展示队列、进度、结果和
   默认折叠的日志；操作表单占满内容宽度，不与任务详情并排。

性能参数默认自动读取 `output/benchmarks/machines.json`。配置摘要会显示实际参数和
“本机实测 / 手动指定 / 默认值”来源；取消自动选项后可以手动覆盖。没有匹配画像时
明确回退到默认值，正式任务不会自动启动 benchmark。重启 WebUI 后使用此入口。
benchmark 命令见 [构建与运行说明](BUILD.md#本机性能画像)。

### 跑谱

选择纯 MCTS 或已发布教师，设置样本目标、模拟数、种子、设备及 worker。
数据批自动命名。已停止/暂停批次从清单恢复，沿用原教师与来源协议，不改变批次身份。

### 双头训练

训练配方显示原始文件 ID，例如 `double-tower.yaml`；配置摘要同时显示架构 ID
`smnet-b9c64dt`。配方 ID 和架构 ID 分别保留，不以泛称代替。

勾选多个数据集，在配置表中逐项填写权重和前缀 limit；0 limit 使用整个来源，零权重
不贡献累计规模。父模型留空从头训练。开始前检查父模型谱系和架构冲突。
高级训练参数可调整验证比例及划分种子；小批数据若没有分出验证局，应提高验证比例。
默认价值训练 → 冻结价值训练策略 → 合并 → 正式 `.safetensor` 发布。
本轮与继承来源按 source_key 去重取最大前缀覆盖数，发布名 `sN` 使用累计规模。

### 评测与评分

默认 NN-MCTS，同时运行相同模拟预算的纯 MCTS；策略头/价值头评测运行随机基线。
完整结果导入评分池；也可选择已有完整评测记录单独导入。
评分表按评分线和协议分组，显示评分、95% 区间、局数及平均得分。
首次评测初始化缺席的锚点；已有锚点不会随新评测改变。缺锚点显示原因、评分留空。
需要更换基准时展开“查看评分结果”中的“设置评分基准”，选择评分池模型，检查后确认。

### 完整迭代

本页独立配置跑谱、训练和评测参数，执行
`selfplay → train → publish → evaluate → rate`。完整模型评测使用发布身份；价值半模型
诊断保留训练身份。可选历史迭代续跑；勾选重做使所选上游及下游失效，旧发布仍保留。
跑谱与评测共用本次迭代的对局并行设置；教师推理、训练与评测共用所选设备。

## 停止、恢复和关闭

- 排队任务点击停止即取消；运行任务在安全边界停止保存，可能需要等待当前局结束。
- 已停止/失败/中断任务点击继续，在队尾复用原任务身份、配置和断点。
- 训练停止保留 `last.pt`，不进入合并或发布；验证中断后重做验证。
- 未完成评测不进入评分池，继续时重做未完成评测臂，保留已完成臂。
- 关闭浏览器后任务继续。正常关闭 WebUI 服务器（Ctrl+C）会请求当前任务保存停止。
- 服务器被强制结束时，任务监护会请求停止保存；60 秒仍未退出则清理整个任务进程组。
  超时清理只保留已提交数据与断点，未提交的棋局或训练批可能丢失。
- 跑谱详情显示搜索速度与已完成模拟数；样本按完整棋局提交，首批棋局结束前已保存样本
  可以为零，搜索进度仍持续更新。CPU 搜索与标注耗时占比用于判断瓶颈。
- 异常退出后不能验证的任务显示“中断”，查看错误与日志后继续，不会仅凭 PID 接管。

任务目录为 `output/jobs/job-<UTC 日期流水号>/`，含 `request.json`、`status.json`、
`result.json`、`worker.log` 与 `work/`。同一输出根只能启动一个队列服务器。
详情提供“用于对局”“用于评测”“作为下一轮父模型”，只填入选择框，不自动连接。
