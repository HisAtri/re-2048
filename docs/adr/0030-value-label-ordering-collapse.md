# ADR 0030：MCTS 退化源于价值标签的"同根排序"信息在自蒸馏中塌缩

- 状态：已采纳（诊断）；**处方经实测收敛**：第一版"改用主轨迹回报"被否（§4）、
  "更高的教师模拟数"被否（§6.2）、"用深度替代启发式先验"也被否（§6.5），被证实的是
  "**换 rollout 的续弈策略**"（§6.1），**线级验证了退化不再复现**（§6.4），
  且该先验没有压制探索（§6.6）。已落进代码：`--rollout-policy`、`iterate` 首轮教师默认 `greedy`。

  §3 用来对照的"立即得分 r 的 std"口径（全局 vs 同根）已由 [ADR 0034](0034-a-versus-r-plus-a-ranking.md) 订正。
- 日期：2026-10-08

## 1. 退化是真的

用户提出：三轮自举中**离线指标全面变好、搜索强度却回落**。先确认退化不是噪声：
同一 eval seed、各 400 局、按局配对（**协议完全一致**：64 lanes / in_flight 16 / 256 模拟），
dt3 − dt2 = **−1511 分（95% CI [−2691, −339]）**，区间不含 0；逐局 dt2 更好 228 局、
dt3 更好 172 局。

完整标尺（锚点：纯网络 track 用 `random` = 1000，搜索 track 用 `mcts256` = 1000；
标尺 = 1000 + 230·Δln(均分)）：

| 臂 | 协议 | 均分 | 评分 | 平均步数 |
|---|---|---:|---:|---:|
| mcts256（纯 rollout，C++） | 256 模拟 | 22,599.7 | 1000.0 | 1218.0 |
| mcts64（纯 rollout，C++） | 64 模拟 | 15,256.3 | 865.0 | 874.6 |
| dt2-nnmcts256 | 256 / in_flight 16 | 18,975.6 | 944.6 | 1044.8 |
| **dt3-nnmcts256** | 256 / in_flight 16 | **17,464.2** | **900.5** | 970.4 |
| dt1-policy（纯网络） | — | 1,681.6 | 1127.1 | 159.5 |
| dt2-policy（纯网络） | — | 2,302.9 | 1239.4 | 202.3 |
| dt3-policy（纯网络） | — | 2,420.5 | 1262.0 | 210.7 |
| dt1-value（纯网络） | — | 3,952.4 | 1416.3 | 290.9 |
| dt2-value（纯网络） | — | 5,254.1 | 1514.0 | 362.3 |
| dt3-value（纯网络） | — | 4,983.5 | 1497.7 | 348.3 |

**策略头逐轮在变好（1,682 → 2,303 → 2,421），搜索强度逐轮在变差（18,976 → 17,464）。**
离线指标（策略一致率、CE）量的正是策略头，所以"指标变好、搜索变差"不是矛盾，而是
**两个组件朝相反方向走**。至今 NN-MCTS 在任何预算下都没有超过同预算的纯 rollout MCTS。

## 2. 一个必须先说的协议事实：in_flight 会改变搜索强度 43%

| 同一个模型（dt1，64 模拟） | in_flight | 均分 | 步数 |
|---|---:|---:|---:|
|  | 4 | **14,226** | 824 |
|  | 16 | **8,119** | 515 |

原因：批量引擎按 in_flight 并发推进模拟，回填是成批发生的——in_flight 越大，PUCT 用到的
统计越陈旧，"64 次模拟"里的重复选择越多。**它是搜索质量与吞吐的取舍，不是纯粹的打包旋钮。**

两个直接后果：

* 我一度以为"64 模拟下 dt1 的模型 14,226 ≫ dt3 的 7,956，所以逐轮在崩"。**那是假象**：
  两者 in_flight 不同；同协议下 dt1 = 8,119 ≈ dt3 = 7,956。**逐轮退化只在 256 模拟
  （in_flight 同为 16）下成立**，也就是第 1 节那个配对结果。
* 评测应当用小 in_flight（搜索更强，吞吐不重要），跑谱用大 in_flight（吞吐优先）。
  协议哈希已经把 in_flight 算进去了（`7ed6a581…` vs `a5d437a4…`），所以这两组数据
  从未被静默混合——P0 的协议收口在这里救了场。

## 3. 根因：价值标签的"同根排序"信息塌缩

引擎的选择逻辑把 Q 在**同一决策节点内**做 min-max 归一化（`batched_engine.cpp:448-469`），
所以价值头对搜索的作用几乎只有一件事：**给同一局面的几个候选排序**。绝对水平无关紧要
——这也解释了为什么"候选标签的水平只有真实回报的 1/25"长期没有致命后果。

于是关键是标签的**同根**（同一局面内候选之间）信息。三个数据批的同根统计：

| 数据批 | 教师 | 同根标签 std（中位） | argmax(访问数) == argmax(标签) |
|---|---|---:|---:|
| dt1 | **纯 rollout MCTS-64**（每条候选边各自的 rollout 均值） | **55.5** | **0.820** |
| dt2 | NN-MCTS-256，其 Q̄ 建立在**上一轮价值头**上 | **17.2** | **0.578** |
| dt3 | 同上（再蒸馏一轮） | **16.5** | **0.583** |

参照量：立即得分 r 的 std = 58.8。也就是说——

* rollout 教师给出的同根振幅（55.5）与"这一手能立刻合多少分"同量级，排序自洽度 0.82
  ⇒ 价值项携带**真实的搜索判断**。
* NN 教师给出的同根振幅只有它 1/3，排序自洽度掉到 0.58 ⇒ 价值项与"立刻合几分"比是噪声，
  **搜索的利用项被立即得分主导，MCTS 退化成贪心合并**（步数从 874 掉到 970 后开始掉头，
  纯网络贪心臂的步数只有 290-360 就是这个症状）。

**订正（ADR 0034）**：上面拿来对照的"立即得分 r 的 std = 58.8"是**全局**口径（跨所有局面、
含大合并的尾部；同类批实测 65.0/81.6），而同根比较里该看的量是**同根** r 的 std——实测中位只有
**3.8 分**（p90 = 20）。两个口径不可比：按同根口径，这一节描述的排序是**价值项主导**（A 的同根
std 55~196 对 r 的 3.8），而不是"立即得分主导"。本节的结论（同根排序塌缩是退化机制、教师必须
给出非循环的同根估计、深度不解决它）不依赖这句话；受影响的是"搜索的利用项被立即得分主导"这个
说法——它只在 A 的同根振幅掉到 r 的量级（个位数）时才成立，那是旧线同根 std 16.5 仍**未**达到的
水平。

闭环因此成立：**NN 教师的 Q̄ 来自上一轮价值头的叶值 ⇒ 标签的同根排序 ≈ 自己的噪声 ⇒
下一轮价值头学到的同根排序更差 ⇒ 驱动的搜索更弱 ⇒ 又产出更差的标签。** 训练日志里
正偏置 +32 → +83 → +111 是这个闭环的指纹。这就是用户说的"污染 MCTS"，机制是
**同根排序信息塌缩**，不是"过拟合到噪声"（两者都表现为离线 MAE 变好——因为验证集来自
同一批自生成标签）。

## 4. 被否掉的处方：改用主轨迹回报（`--value-target trajectory`）

第一版诊断把它当成"标签用错了量"，处方是改用真实回报。实测**四处全都更差**：

| 实验 | 对照组 | 改后 |
|---|---:|---:|
| dt1 批、只换价值半模型、64 模拟 / in_flight 4 | 14,226 | **3,157** |
| dt3 批、只换价值半模型、64 模拟 / in_flight 16 | 7,956 | **2,211** |
| 纯网络贪心（dt1 的批与策略头） | 3,952 | **868**（随机 1,085，步数 103） |

为什么错：真实回报只标注**实际走过的那个候选**，同根比较的信息被丢掉；而且它是**单样本**
（std 7,118 对均值 9,208）。所以它的绝对水平无偏、能拟合到 0.8σ 噪声下限，但**同根排序
比候选标签更差**——而排序才是搜索需要的东西。**"绝对无偏"不等于"对搜索有用"。**

顺带否掉两条相邻路线：给候选标签乘常数校正（同根振幅与标度无关的问题，乘法无用）；
把候选块整体丢掉（等于丢掉唯一的同根信号）。

### 4.1 补测：量纲**不是**无关紧要的（同一批实验里的自我订正）

我一度以为"引擎在同根内 min-max 归一化 Q，所以价值头的绝对水平无关紧要"。**这是错的。**
把同一个模型的价值头输出整体缩放后重跑同协议评测（400 局、64 模拟、in_flight 16、同 seed）：

| 价值头 | 有效量级 | 均分 |
|---|---:|---:|
| dt1（候选标签）÷10 | ≈30 | 8,787 |
| dt1（候选标签）原样 | ≈300 | **8,119** |
| dt1（候选标签）×10 | ≈3,000 | 5,988 |
| dt1（候选标签）×30（未测，趋势外推） | ≈9,000 | — |
| dt1 + 真实回报头，原样 | ≈9,000 | 3,157 |
| dt1 + 真实回报头 ÷30（量级与候选头对齐） | ≈300 | **3,561** |

原因：`one_ply / Q = r + A` 把**真实得分**与 A 相加，树里的 Q 又沿路径累加真实得分，
所以 A 的量级相对"得分"决定了搜索信任价值还是信任自己一路累加的分。**两个旋钮被焊在一起：
"用哪种标签"会顺带改变"价值占多大权重"。**

两点后果：

* 先前"真实回报目标更差"的 A/B 确实混进了量纲这个变量。**但补上量纲匹配的对照后结论不变**：
  对齐量级只回收了约 400 分（3,157 → 3,561），仍远低于 8,119。**真实回报不是好的价值目标**，
  原因在它只标注实际走过的那个候选（丢掉同根比较）且是单样本。
* 缩放曲线是**单调**的：在这族价值头下量级越小越好（30 → 8,787 略优于 300 → 8,119，≈2σ；
  而放大到 3,000 掉到 5,988，≈6σ）。最自洽的读法是"当前价值头带来的净信息很弱，
  它的影响更像与 |A| 成正比的噪声"——所以**在价值头变好之前，任何"把价值目标换成更'正确'
  的量纲"的改动都会顺带把它推到更有害的一侧**。这也是"标签定义"必须与"价值权重"解耦的理由。


## 5. 结论与下一步

**改动顺序**：先修标签从哪来，再谈损失与权重——因为实验已经给出明确的排序（§6）：
换续弈策略带来 3.4 倍的同根区分度和翻倍的学生强度，换价值目标、换教师模拟数都是负收益。

1. **保留候选级监督**（同根比较是搜索唯一用到的东西），**教师必须给出非循环的候选估计**
   （纯 rollout，不建立在自己头上），而且**续弈策略要尽量强**——这是被证实的那一条：
   一步启发式（走完空位最多）就把标签同根 std 从 55.5 抬到 186.2、学生强度翻倍，
   而**教师棋力的提升本身不解释任何事**（棋力相当的均匀 256 教师训出的模型反而更弱）。
   已落进代码：`--rollout-policy`，`iterate` 首轮教师默认 `greedy`。
2. **下一步优先级**（按被证实的程度排）：
   * 把续弈策略继续做强（一步启发式只是最便宜的版本：加入单调性/角块/平滑度的加权启发，
     或做 2 层 expectimax）；每一档都要用同一套便宜判据量（标签同根 std + 纯价值贪心臂）。
   * 自举时把价值标签与策略标签分开取：策略标签可以来自 NN 搜索（它下得更好），
     价值标签仍由非循环的 rollout 教师给——实现上是给每局加一趟标注（记录格式已容得下）。
   * 同根相对损失（§下一条）在标签改善之后再上，避免同时动两个变量。
3. **损失改成同根相对量，并把量纲显式钉住**：主项用同根相对目标（减去该节点加权均值）或
   同根成对排序损失——搜索用的就是同根排序，而失效模式正是"同根振幅塌缩"；同时配一个显式的
   尺度锚（除以固定参考尺度，或对实际走过的候选保留一个小权重绝对项），否则量纲会像 §4.1
   那样隐式改变搜索性格。
4. **把"价值权重"变成搜索侧的显式协议参数**（可选但便宜）：现在"信任 A 还是信任沿路累加的
   得分"完全由 A 的量级决定，而 A 的量级由标签定义决定——两个本应独立的旋钮被焊在一起。
5. **评测纪律**：跨臂比较必须 **in_flight 与模拟数同时匹配**；评测用小 in_flight。
6. **验收判据**：**纯价值贪心臂**（3 秒）+ **NN-MCTS 在匹配协议下的绝对强度**。
   离线指标（策略一致率、CE、候选 MAE）在这条链上是**反向指标**（它们量的是"拟合自己的
   教师"），不再单独作为进度依据。"同模拟数对比 NN 与纯 rollout"要注意两边一次模拟的
   代价相差百倍（§6.3），报告时两个轴都要写。
7. 本次顺手修掉的未来坑：`model_id` 与元数据 `value_target` 现在都显式记录价值目标
   （旧写法下"候选目标"和"主轨迹回报"训出的两份不同权重同名，评分池按 model_id 去重会把
   它们当成同一个模型；实测已发生）；`--rollout-policy` 进协议参数、进来源身份，且
   `verify` 的重放会恢复它（漏恢复时它报的是"分片哈希不一致"，看起来像数据损坏——已修）。
8. **dt3 那一轮的数据生成侧还有第二个混淆**（见 ADR 0031）：dt3 用 `--search-threads 8`
   产出数据，而实测该模式下**同一 (种子, 局号) 两次运行会下出不同的棋**。所以"dt2 → dt3
   退化"同时混着"教师换了"与"数据生成模式换了且不可复现"两件事，**单跑一次分不开**；
   要定位必须用同线程数的对照或配对设计。数据生成从此限定 `--join` 多进程（已定）。

## 6. 验证（同种子、同构建、单变量）

为了把"量到的东西"和"要改的东西"对上，做了一组**单变量**实验：同一构建、同一种子
（20261007）、同一 64 模拟，只改**教师的产出方式**；两批数据（各 100 万条）用**同一配方**
（value run → 冻结价值训策略头 → 合并，同种子 20261007/20261008）训出模型，再在同协议
（64/256 模拟、`in_flight 16`、400 局、评测种子 20262053）下评测。

| 教师（均为纯 C++，无网络） | 教师棋力（该批的局均分） | 标签同根 std | 标签自洽度 | Q̄ 均值 | 样本/局 |
|---|---:|---:|---:|---:|---:|
| 均匀续弈 64 模拟 | 15,207 | 55.5 | 0.820 | 386 | 872 |
| 均匀续弈 256 模拟 | 22,863 | 41.5 | 0.821 | 358 | — |
| **启发式续弈 64 模拟** | 22,357 | **186.2** | **0.845** | **1,118** | 1,198 |

| 学生模型（同一配方） | 纯价值贪心（3 秒） | NN-MCTS-64/if16 | NN-MCTS-256/if16 |
|---|---:|---:|---:|
| t64（均匀 64 教师） | 3,736 | 8,306 | 16,906 |
| t256（均匀 256 教师） | 2,855 | 6,388 | 13,136 |
| **tG（启发式 64 教师）** | **8,185** | **13,156** | **27,419** |
| 纯 rollout MCTS（同模拟数对照） | — | 15,256 | 22,600 |

**验收判据第一次达成**：tG 在 256 模拟下 **27,419 > 纯 rollout MCTS-256 的 22,600**，
按局配对的差 +4,819（95% CI [+3,131, +6,490]，230 胜 1 平 169 负，400 局同 seed）——
项目历史上 NN-MCTS 第一次在同模拟数下超过纯 rollout MCTS。64 模拟下 tG = 13,156 仍略低于
rollout-64 的 15,256（14%），但相对之前的 8,306 已翻 1.6 倍。

### 6.1 被证实的那一条：续弈策略是标签信息量的上限

把 rollout 的续弈策略从"均匀随机"换成"一步启发式（走完空位最多的方向）"——
**搜索深度完全不变，仍是 64 模拟**——得到：

* **标签的同根信息量涨 3.4 倍**（同根 std 55.5 → 186.2），自洽度 0.820 → 0.845，
  量级也从 386 升到 1,118（真实回报约 14,000，方向正确）；
* **学生模型两条臂都翻倍**：纯价值贪心 3,736 → **8,185**，NN-MCTS-64 8,306 → **13,156**，
  NN-MCTS-256 16,906 → **27,419**；按局配对比 t64 高 **+10,513**（95% CI [+8,949, +12,100]，
  288 胜 111 负）。

而且这个改善**不能**用"教师更强"解释：启发式教师的棋力（22,357）与均匀 256 模拟教师
（22,863）**相当**，但后者训出的模型只有 6,388（贪心臂 2,855）。所以：
**模型强度跟着标签的同根区分度走，而不是跟着教师的棋力走。** 这正是 §3 的机制预言。

代价与工程后果：启发式 rollout 每样本约 4.4 倍算力（3860 vs 16934 样本/秒），
换来的是"棋力等于 4 倍模拟、标签区分度等于 4.5 倍"——按算力算它是**严格更划算**的教师。
它的可复现性也验证过：`verify --replay-workers 8` 重放 16 worker 产出的批，逐分片哈希一致。
已落进代码：`--rollout-policy uniform|greedy`（`GenerateConfig` + `RolloutMctsConfig`），
进 `kProtocolParams` 与 Python 的 `SOURCE_KEY_PARAMS`（属协议参数、进来源身份），
`iterate` 的首轮教师默认值改成 `greedy`。

### 6.2 被否掉的那一条：更高的教师模拟数

均匀续弈把模拟数从 64 提到 256（4 倍算力）后：教师棋力 15,207 → 22,863（强了 50%），
但**标签的同根 std 反而降到 41.5**、与真实回报的分层秩相关原地不动，学生模型
**两条臂都变差**（贪心 3,736 → 2,855，NN-MCTS-64 8,306 → 6,388）。
读法：64 模拟下那点多出来的 std 里有相当一部分是**估计噪声**（每个根边的访问数少），
加深搜索把噪声压下去了，却没能提高信号——因为信号被**均匀随机的续弈策略**洗掉了。
所以"教师更强 ⇒ 数据更好"不成立；**强在续弈策略上才算强**。

### 6.3 度量：哪些指标可信，哪些不可信

* **可信且便宜**：纯价值贪心臂（`track=nn_value`，400 局 3 秒）。三组里它与搜索臂**同向且
  同步**（3,736↔8,306、2,855↔6,388、8,185↔13,156），是"值得不值得跑一次完整评测"的快速判据。
* **要限定条件**：我原先建议的"固定对外尺子"（在一批独立数据上量同根排序一致率）
  只能**在同一续弈策略内部**比较。实测：均匀教师训出的两个头在这把尺子上几乎不可区分
  （成对 0.541/0.535，命中 0.358/0.347，上限 0.919/0.857），而启发式教师训出的头
  同根预测 std 从 18.9 升到 62.6 **却在这把尺子上没有更高的一致性**——因为两种教师的
  排序本来就不同，尺子量的是"像不像那把特定的教师"。
* **终局判据仍需注意口径**：rollout 引擎的一次"模拟"是**走到终局**（约上百步），
  NN 引擎的一次"模拟"是一次叶评估。所以"同模拟数对比 NN 与 rollout"对 NN 有利、
  "同墙钟"的结论又不干净。报告时必须把两个轴都写出来，不能只说"同模拟数"。


## 6.4 线级验证：退化没有复现（这是本轮要回答的问题）

把新配方走成一条**三轮的线**（同一构建、同一配方、每轮 100 万条、每轮从上一轮模型继续，
评测一律 256 模拟 / `in_flight 16` / 同 seed / 400 局）：

| 轮次 | 教师 | 数据的标签同根 std | 纯价值贪心 | **NN-MCTS-256** | 旧线同一轮的 NN-MCTS-256 |
|---|---|---:|---:|---:|---:|
| r1 | 纯 rollout **greedy** 64 模拟 | 186.2 | 8,185 | **27,419** | 17,132（dt1） |
| r2 | NN 自对弈 256 模拟（r1 模型） | **172.9** | 10,166 | **28,131** | 18,976（dt2） |
| r3 | NN 自对弈 256 模拟（r2 模型） | **145.6** | 11,087 | **31,181** | 17,464（dt3） |

逐转移的按局配对（同 seed 400 局）：

| 转移 | 旧线 | 新线 |
|---|---|---|
| r1 → r2 | +1,844（CI [+735, +2,945]）显著上升 | +712（CI [−1,178, +2,642]）不显著 |
| **r2 → r3** | **−1,511（CI [−2,691, −339]）显著退化** | **+3,051（CI [+1,045, +5,044]）显著上升** |
| r1 → r3 累计 | −332（净零） | +3,763（CI [+1,648, +5,865]） |
| r3 vs 纯 rollout MCTS-256 | −3,624（从未超过） | **+8,582（CI [+6,791, +10,375]，262 胜 138 负）** |
| r3 vs 旧线最好一轮 | — | +12,206（CI [+10,534, +13,908]，295 胜 103 负） |

三条同时成立，才叫"退化解决了"：

1. **那一处退化没有复现**：旧线在第二次转移掉 1,511（显著），新线在同一步涨 3,051（显著）。
2. **机制指标不再塌缩**：旧线的标签同根 std 是 55.5 → 17.2 → 16.5（自蒸馏把区分度洗掉），
   新线是 186.2 → 172.9 → 145.6（稳定在高位；缓慢下降与模型收敛同向，不是塌缩）。
3. **绝对水平远超基线**：r3 在 256 模拟下比纯 rollout MCTS-256 高 38%，比旧线最好一轮高 64%。

注意第一条的读法：r1 → r2 在两条线上都不算"退化"，所以**新线的第一转移持平并不构成证据**；
能说明问题的是第二转移——旧线在那里掉了，新线涨了。另外 r2 的标签 std（172.9）低于 r1 的
教师标签（186.2）而模型更强，说明"标签区分度"与"学生强度"是同向而非同一量，别把前者当终点。

## 6.5 深度不是杠杆：同数据量下"深化"比"换续弈策略"差一个数量级

用户提出的备选假设是"不做启发式、减少样本量、增加搜索深度，退化是否缓解"。做了同数据量
（20 万条）、同配方、同 seed 的三方对照：

| 教师（纯 C++，同为 20 万条） | 标签同根 std | 纯价值贪心 | NN-MCTS-64 | NN-MCTS-256 |
|---|---:|---:|---:|---:|
| 均匀续弈 64 模拟 | 55.5 | 1,544 | 4,111 | 9,230 |
| 均匀续弈 **1024** 模拟 | 37.0 | 1,152 | 2,762 | 5,574 |
| **启发式续弈 64 模拟** | **186.2** | **3,924** | **8,214** | **25,059** |

按局配对（同 seed 400 局，全部显著）：

| 对照 | 差 | 95% CI | 胜负 |
|---|---:|---|---|
| 续弈策略 vs 均匀-64（256 模拟） | **+15,829** | [+14,419, +17,269] | 347:53 |
| 续弈策略 vs 均匀-1024（256 模拟） | **+19,485** | [+18,080, +20,925] | 373:27 |
| 均匀-1024 vs 均匀-64（256 模拟） | **−3,656** | [−4,160, −3,166] | 86:314 |
| 续弈策略 vs 均匀-64（64 模拟） | **+4,103** | [+3,578, +4,632] | 321:79 |

**结论：深度方向是负的，而且单调。** 完整深度扫描（同 seed，200k）：

| 教师模拟数 | 64 | 256 | 1024 | 2048 |
|---|---:|---:|---:|---:|
| 标签同根 std | 55.5 | 41.5 | 37.0 | 35.4 |
| 与访问数自洽 | 0.820 | 0.821 | 0.861 | 0.863 |
| Q̄ 均值 | 386 | 358 | 367 | 368 |
| 该批真实回报均值 | 9,208 | 13,542 | 15,002 | 16,219 |

读法：**表观同根 std = √(信号² + 噪声²)**，信号恒在 ≈35 分，多出来的部分在低模拟数下全是
估计噪声；加深搜索只是把噪声压掉，露出的信号并没有变大，而**量级始终停在 368**（真实回报
16,219，差 44 倍）——量级由**续弈策略**决定（启发式的 Q̄ 均值是 1,118），与深度无关。
加深还顺带把决策分布变集中了（见 §6.6），对数据探索是负面的。

顺带得到一个数据效率的观察：启发式教师 20 万条就拿到 25,059，是它 100 万条那条腿
（27,419）的 91%；均匀教师 20 万条只有 9,230，是它 100 万条（16,906）的 55%。

## 6.6 "引入先验会不会破坏探索自由度"：实测没有，而且深度才是压制探索的那个

启发式只加在 **rollout 的续弈里**（叶子的估值方式），不在**树的策略**里：
`select_action` 的 UCT 探索项、以及"每条合法边至少访问一次"的规则都没动
（`cpp/search/rollout_mcts.cpp`）。所以决策点上的探索是**结构性不变**的。实测三个层次：

| 数据批 | 候选覆盖（全部合法候选都被标注） | 合法边被访问（visits>0） | 策略目标熵（归一，1=均匀） |
|---|---:|---:|---:|
| 均匀 64 模拟 | 1.0000 | 1.0000 | 0.671 |
| 均匀 256 模拟 | 1.0000 | 1.0000 | **0.464** |
| **启发式 64 模拟** | 1.0000 | 1.0000 | **0.699** |
| NN 自对弈（新线 r2） | 1.0000 | 0.9872 | 0.698 |
| NN 自对弈（新线 r3） | 1.0000 | 0.9228 | 0.694 |

* **候选覆盖恒为 1.0000**：每个局面的全部合法候选仍然有标签——监督的覆盖面没被先验碰过。
* **合法边被访问 ≈ 1**（纯 C++ 路径恰好 1.0000，UCT 未访问优先的规则生效；NN 自对弈的批
  0.92–0.99，来自批量引擎的在途调度，与先验无关）。
* **决策分散度没有下降**：启发式教师 0.699 反而略高于均匀-64 的 0.671；真正把决策变集中
  的是**加深均匀搜索**（0.464）。也就是说，如果关心"探索自由度"，该警惕的是深度而不是先验。

先验的真实代价（诚实交代）：标签不再是"策略无关"的量——它变成"在某个固定启发式续弈下
的价值"。因此 (a) 它把我对"空位重要"的设计判断写进了**目标**里，若该判断在某个局面族上
系统性错误，价值头会继承这个偏差（但搜索仍可用沿途累加的真实得分压过它）；
(b) rollout 内部的动作多样性消失（随机性只剩随机块）——估计量方差下降是好事，
但"估计器自身的探索"确实少了。

它的**作用范围是有限的**：只有第一轮引导教师用它。r2、r3 的标签全部来自 NN 自对弈
（模型自己的搜索，完全不含启发式），而这两轮仍在上升（28,131 → 31,181）。
即它是**一次性引导**，不是长期拐杖；一旦价值头有了真实的同根区分度，自举自己就能维持
（这正是 §3 讲的那个闭环在**信息量足够**时是良性循环、在信息量塌缩时是恶性循环的原因）。

## 7. 证据清单

* **退化没复现（本轮要回答的问题）**：§6.4 表——旧线第二转移 −1,511（显著），新线同一步
  +3,051（显著）；新线 r3 在 256 模拟下 31,181，比纯 rollout MCTS-256 高 38%（配对 +
  8,582，262:138），比旧线最好一轮高 64%（配对 +12,206，295:103）。
* **深度不是杠杆**：§6.5 表（同 20 万条数据，均匀 64 → 1024 使学生从 9,230 掉到 5,574，
  配对 −3,656；而换续弈策略同数据量下是 +19,485）。
* **先验没有压制探索**：§6.6 表（候选覆盖 1.0000、合法边被访问 ≈1、决策熵 0.699 vs 均匀
  0.671 而深化到 256 是 0.464）。
* **退化真实**：协议一致的 400 局配对差 −1511（95% CI 不含 0）；逐局 228:172。
* **in_flight 效应**：同模型同模拟数 14,226（if 4）→ 8,119（if 16）；协议哈希已区分两组。
* **同根塌缩**：标签同根 std 55.5 → 17.2 → 16.5；与自身访问数的一致性 0.820 → 0.578 → 0.583；
  立即得分 std 58.8 作为"是否有信号"的参照。
* **标签来源**：dt2/dt3 的 manifest `model_id` 指向上一轮模型（自蒸馏，代码路径
  `rollout_mcts.cpp` 的均匀抽样 rollout / `batched_engine.cpp:682-699` 写候选标签）。
* **处方一被否**（主轨迹回报）：量纲匹配前后都远差于候选目标（3,561 vs 8,119）。
* **处方二被否**（更高模拟数）：§6.2 表（教师更强而学生更弱）。
* **处方三被证实**（续弈策略）：§6.1 表（同深度下标签 std ×3.4、学生两臂翻倍）；
  验收判据达成——256 模拟下 27,419 vs 纯 rollout 22,600，配对差 +4,819（CI [+3,131, +6,490]）。
* **量纲不是无关的**：§4.1 表（÷10 → 8,787，原样 → 8,119，×10 → 5,988）。
* **复现性**：纯 C++ 路径同参数同种子逐字节可复现（新构建重跑 dt1 的批，10 个分片
  sha256 全同；启发式续弈的批 `verify --replay-workers 8` 也通过）。多线程产出的数据  不可复现，见 ADR 0031。
* **尚未验证**：同根相对损失（§5 第 3 条）能否在已改善的标签上再进一步；
  更好的续弈策略（单调性/角块启发、2 层 expectimax）能把它推到多高；64 模拟这一档为何
  仍低于 rollout-64（14%）；把价值标签与策略标签分开取（NN 出谱 + rollout 标注）是否更好。
