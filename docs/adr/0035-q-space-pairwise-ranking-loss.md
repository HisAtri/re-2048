# ADR 0035：Q 空间的同根成对排序项——贪心判决 +19%（显著），但 256 模拟的搜索不动

- 状态：已采纳（机制在被瞄准的那个口径上生效；**默认开启** `value_ranking_weight = 1.0`——初版写的是默认关，补测后改开，理由见「换预算测量」一节）
- 日期：2026-10-08

## 背景

ADR 0034 把口径问题钉清了两半：

* **回归项对 r 不变**：`(pred+r) − (target+r) = pred − target`，所以 Huber/MSE 在 A 空间与
  Q = r + A 空间逐值相同——这正是"价值头只能训 A"的由来（r 不是 afterstate 的函数）。
* **但成对的排序标签会变**：A 口径比 `target_a vs target_b`，Q 口径比
  `target_a + r_a vs target_b + r_b`，在 r6 的批上 **12.9% 的根给出不同的 argmax**。

所以"r+A 才是正确的口径"这句话落在**排序项**上，而不是回归项，也不是 checkpoint 挑选
（挑选那一条已实测为空实验：两臂权重逐位相同）。而且 Q 空间的排序目标有明确语义：
`target_Q = r + candidate_value = Q̄`，正是**教师自己的边均值 Q**——对搜索输出最忠实的蒸馏。

## 决策

1. **新增 `value_ranking_weight`**（默认 0 = 关）与 `_ranking_loss()`：对每根的每对合法候选，
   令 g = 目标 Q 间隔、h = 预测 Q 间隔，取

   ```
   loss_ab = |g| · σ(−h · sign(g) / τ)                    τ = 20 分（让步界限）
   ```
   **（已订正，见 ADR 0043 的实现审查）**：初版写的是 `τ · softplus(−h·sign(g)/τ)`。它的两个因子
   都是分数 ⇒ 量纲是**分数平方**，归一化后只乘一次 `score_scale` 也给不出"分/根"，所以下面
   "量纲与 Huber 的 MAE 可比"那句当时**不成立**。改用无量纲的软化指示子 `σ(·)` 之后，这一项
   就是该对的期望后悔、量纲是**分数**，那句解释才成立（顺带消掉了软 hinge 的无界梯度）。

   按**根**取平均（不是按间隔和，否则会被"间隔大、本来就容易对"的对稀释一个量级）。
   理由：
   * `σ(x/τ)` 在 `x ≫ τ` 时趋 0、`x ≪ −τ` 时趋 1，所以这一项在极限上等于**成对后悔**的
     软化指示子：符号对就趋 0、符号错就趋 |g|。用 |g| 当权重 = "按这一对值多少分罚"，
     **量纲是分数**、与 Huber 的 MAE 可比，`value_ranking_weight` 于是有直接含义；
   * 只看**符号**、不要求间隔匹配：决策只取决于 argmax；
   * τ 取 20 分 ≈ 这条线候选 MAE 的一半——更小的间隔本来就埋在价值头的误差里；
   * Huber 保留作**尺度锚**（ADR 0030 §4.1 要求量纲显式钉住），这一项只加"符号"压力。
2. **默认开启（`value_ranking_weight = 1.0`）。** 初版写成默认关，理由是「验收臂（256 模拟）
   是平局，在验收不动时改默认值是往配方里写噪声」。**补测推翻了那个前提**：把模拟数降到
   8/16/64 并各跑 4000 局之后，配对差**显著为正**（+466 / +399 / +371，见「换预算测量」）
   ——原来的「平局」是 400 局在 256 模拟上的**分辨率不足**，不是没有效应。现在有标准臂
   （64 模拟）上的显著胜绩，默认随之打开；256 模拟那一档仍只能给出方向（点估计 +405）。
3. 权重进 `model_id`（`+rank1`）与 checkpoint metadata；排序项自身的量级（分/根）进日志、
   `train.json` 与 metadata——否则"加了排序项"会变成一个看不见的配方改动。

## 结果

配方：与 r6 的价值 run **完全同数据（`g1-r6-s256-*`）、同 init（g1-r5 的合并模型）、同种子
20261007、同 8 轮、同架构**，只加 λ=1 的排序项。策略半复用 r6 的 `policy-head`（它不读价值
run 的产物），合并后与 r6 的模型只差价值半。

**离线（选中的 epoch）**：

| 指标 | 对照 r6（epoch 7） | 处置（epoch 8） |
|---|---:|---:|
| 候选 MAE（A 口径） | 40.6 分 | 41.8 分（**略差**） |
| A 口径最优命中 | 66.66% | **67.79%** |
| r+A 口径最优命中 | 65.84% | **67.18%** |
| r+A 口径后悔 | 12.0 分 | **10.78 分** |
| 排序项（自身量级，逐轮） | — | 2.93 → 2.48 分/根 |

三个排序指标**同向变好**（含 A 口径），代价是 MAE 多 1.2 分。这是一次很干净的
"拟合精度 vs 决策正确"取舍：新项罚的是"引擎会不会走出教师的判决"，而旧项罚的是"像不像
教师的 A"。

**对局（400 局、seed 20262053、按局配对 bootstrap）**：

| 臂 | 对照 r6 | 处置 rank1 | 配对差 | 95% CI | 判定 |
|---|---:|---:|---:|---|---|
| **纯价值贪心** `nn_value` | 14,870.2 | **17,754.6** | **+2,884.4** | [+1,633.7, +4,124.6] | **显著**（230/1/169） |
| 纯策略 `nn_policy` | 3,477.1 | 3,449.5 | −27.6 | [−296.1, +237.7] | 不显著（预期内：策略半相同） |
| NN-MCTS-64 | 13,027.5 | 13,202.8 | +175.2 | [−919.7, +1,271.1] | 不显著 |
| **NN-MCTS-256（验收）** | 40,175.2 | 40,580.2 | +405.0 | [−2,321.4, +3,120.3] | **不显著** |

相对固定外部锚点（纯 rollout MCTS-256 = 22,600）：**179.6%**（r6 是 177.8%），配对
+17,981 [+15,841, +20,157]。

**排除量纲混淆**：两个价值头在同一批候选 afterstate 上的输出，均值 1659.8 → 1664.4 分、
标准差 709.4 → 710.6（差 <0.3%）。所以搜索臂的任何变化都只能归因于**排序**，不是
ADR 0030 §4.1 那个"量纲漂移改变搜索性格"的失败模式。

## 读法

**1. 机制在被瞄准的口径上确实生效，而且幅度不小。** 纯价值臂 `argmax(r+A)` 是"完全由价值头
的排序决定"的那条臂，它 +19.4%（+2,884，分辨率 ±270）——这是这条线七轮以来**单次改动带给
纯价值臂的最大跃升**（线自身的逐轮增量是 +900~+1,500）。同一个臂上，r6 相对 r5 只有 +1,271。
也就是说：**"只罚改变判决的误差"确实训出了更好的判决。**

**2. 它确实转移到了搜索——初版写的「没转移」是分辨率不足（此节已订正）。**
初版依据是 256 模拟 400 局的不显著结果（+405，CI ±2,700）。补测换了一个更灵敏的仪器：
**降低模拟数**（逐局分数的方差随模拟数下降）并**加大局数**：

| 模拟 | 局数 | 配对差 | 95% CI | 判定 | 胜率 |
|---:|---:|---:|---|---|---:|
| 8 | 400 | +251.4 | [−189.7, +703.0] | 不显著 | 53.4% |
| **8** | **4000** | **+465.6** | **[+321.7, +608.2]** | **显著** | **54.4%** |
| 16 | 400 | +383.1 | [−35.4, +802.9] | 不显著 | 53.0% |
| **16** | **4000** | **+399.3** | **[+263.1, +538.4]** | **显著** | **53.9%** |
| 64 | 400 | +175.2 | [−919.7, +1271.1] | 不显著 | 51.5% |
| **64** | **4000** | **+370.8** | **[+28.2, +711.5]** | **显著** | **50.8%** |
| 256 | 400 | +405.0 | [−2,321.4, +3,120.3] | 不显著 | 50.3% |

四档的配对差**全部为正**，绝对量级大致恒定（+371~+466 分），相对量级随模拟数上升而衰减
（8 模拟 +8.0%、64 模拟 +2.8%）——这与「排序改进在访问数少的地方更值钱」一致，但不构成
「高预算无收益」的证据：256 模拟的点估计（+405）与低预算同向同量级，只是 400 局的 ±2,700
分辨不出来（要分辨 ~+400 需要约 6,000 局）。

**所以初版的机制解释（「搜索在根上自己算排序，把价值头的改进覆盖掉了」）不成立**，至少不足以
解释数据。改后的判断是：价值头的根级排序质量**确实**是搜索强度的一个（小）限制因素，只是它的
收益在当前协议的分辨率之下——这也解释了为什么它此前从未在标准验收里被看见。

**方法学结论（应并入 ADR 0033 的监控口径）**：判一个机制有没有转移，除了「同预算配对」，还要问
**这个判据的分辨率够不够**。低预算臂的逐局分数方差小得多（8 模拟 4000 局 → ±143；256 模拟
400 局 → ±2,700），在效应量小于预算相关的方差时，它才是可用的仪器。这与 ADR 0030 §6.3 的
「纯价值臂分辨率高 3.5 倍」是同一件事的另一面。

**3. 这与 ADR 0033 的观测拼在一起是一条连贯的线**：七轮自举里，价值头一直在变强（纯价值臂
8,185 → 14,870），而 64 模拟那一档从 r1 起就饱和（~13k）、策略头六轮没动过。本轮又证明
"把价值头的判决再推高 19%"也不会抬高 256 模拟的成绩。**搜索的强度不是被价值头的根级排序限住
的**；剩下的候选解释是叶值质量、先验质量（策略头）与探索分配——按 ADR 0032 的结果，策略头
那一侧用 Â 加权的改进也被否过。

## 理由

* **为什么保留实现但关默认**：它零推理成本、无新依赖、有回归测试（只罚改变判决的误差这条语义
  被手算表钉住），并且是"口径一致性"这一原则的唯一落地方式。它现在没有进配方的理由只是
  **验收臂没动**；一旦换到更高模拟预算、或叶值监督也改成同一口径，它应当重跑。
* **为什么不用它替换 Huber**：ADR 0030 §4.1 的实测是"改价值目标的量纲会顺带改搜索性格"，
  排序项不含绝对尺度，单独用它会让尺度失去锚。两条一起才是完整的目标。
* **为什么不直接开默认**：验收臂是平局。按 ADR 0032 的纪律，在验收不动的情况下改默认值，
  是在把噪声写进配方；而且本轮只有 λ=1 一个点，没有剂量-反应证据。

## 替代方案

* **在 A 空间做同样的成对排序损失**：与 Huber 的监督高度重合（A 口径与 Q 口径的排序只在 12.9%
  的根上不同），且它奖励的是"像教师的 A"，不是"做出教师的判决"。本轮的对照（MAE 略差而三个
  排序指标同向变好）说明这两个目标确实不同。
* **只按 r+A 口径挑 checkpoint**：已实测为空实验（ADR 0034）——挑选只能在同一轮训练的不同
  epoch 之间选，影响上界是"相邻 epoch 的差别"。
* **把 r 作为输入特征喂给价值头 / 训 r+A 回归**：让目标不再只是 afterstate 的函数，且把两个
  量纲焊在一起。否（ADR 0034）。
* **扫 λ（0.3 / 1 / 3）找剂量-反应**：未做。它是"搜索不吃这一项"这一结论的直接加强项，
  但按读法 2 的机制解释，加大 λ 应该只继续推高纯价值臂，不会动搜索臂——所以它的信息量有限。
* **把监督改到叶值口径**（用搜索树内部节点的候选而不是轨迹根）：未做，是读法 2 的直接推论，
  也是本轮之后最有依据的下一步。

## 验证方式

* `python/tests/test_data_and_training.py::test_ranking_loss_only_punishes_decisions`：手算表钉住
  语义——完美预测 0、"A 排序错但引擎判决没变"**必须为 0**、"A 排序对但引擎会改选"必须 >0 且
  随错误增大，且有上界（软 hinge 的有界性）。这一条是"排序项到底在罚什么"的唯一直接凭据。
* `model_id` / metadata 里能读出 `+rank1` 与 `value_ranking_weight`；日志给出排序项自身量级。
* 端到端：本轮的训练产物 `exp/rank-r6/`（`runs/value/`、`model.pt`）、逐局记录
  `exp/eval-rank-r6-*.jsonl`；`r2048 compare` 复现全部配对差。
* 量纲对照：两个价值头在同一批候选上的输出均值/标准差（1659.8/709.4 对 1664.4/710.6）。
* **明确未验证**：λ 的剂量-反应；**叶值口径的排序监督**（把监督从轨迹根的候选改到搜索树
  内部节点的候选——引擎的 `Node` 里已经有全套数据，缺的是数据通道：抬记录版本，或另存一个
  数据批，见 ADR 0035 之后的决策）；256 模拟档需要约 6000 局才能把 +405 分辨出来（未做）；
  更高预算（512/1024）的走向；线级实验（把排序项开进下一轮自举，看线的轨迹是否变陡）；
  单轮一个训练 seed。
