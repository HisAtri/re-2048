# ADR 0045：Gradio 工作台的设计系统与操作流程

- 状态：已采纳
- 日期：2026-10-09

## 背景

现有界面把表单、棋盘、操作和分析堆在默认 Gradio 布局里：固定宽度挤压棋盘，编辑缺少预览，
复盘只有一个含义不清的滑块，错误与操作状态缺少明确反馈。仅改变颜色不能解决操作成本。
本决策延续 ADR 0039 的进程协议、可选依赖与流式执行边界，替换页面呈现和交互组织。

## 决策

1. 使用统一工作台：顶部会话卡，下面是对局与分析、局面编辑、棋谱复盘。
   桌面限宽 1280px，对局内棋盘与分析按 5:7 分栏；800px 以下纵向排列。
   棋盘保持正方形，方向表仅在自身区域横向滚动。显式设置外层盒模型，消除 Gradio 默认容器的溢出。
2. 纸面背景与深绿色强调色统一用于按钮、状态、控件边界与选招标记；棋盘保留标准 2048 配色。
   Gradio 原生组件继续承担输入、焦点、键盘和事件，稳定的 `r2048-*` ID 承担页面样式边界。
   `workspace.css` 和 `workspace.js` 随 Python 子包打包；页面样式只加载一次。
   渲染函数默认仍可输出独立组件样式，但实时更新不再逐帧插入 `<style>`。
3. 明确操作层级：开局与自动执行放在棋盘上方，分析按钮放在结果上方，撤销与清空放在棋盘下方。
   搜索与执行设置常驻显示，数值参数有单位、范围与解释；刷新模型列表保留仍然存在的当前选择。
   （2026-10-09 交互修订：这些参数在分析时需要随时核对，取消最初的折叠设计。）
   同行字段的说明统一放到行下方，连接与刷新并排并与输入框等高；参数采用桌面四列、
   平板两列、手机一列布局。Gradio 自动生成的 form 默认铺灰蓝底色，会在列间距里露成竖条，
   因此显式设置该容器透明背景和字段间距。
   模型、设备共同决定连接身份，相同身份重连保留局面，更换身份重建会话。
4. 分析展示实际模拟数、耗时、根值摘要与完整方向表。落子返回的分析属于移动前的根，
   显示为「上一步决策」，不将旧选招方向标在移动后的棋盘上。状态栏保留最近已应用的参数。
5. 编辑器按 a1..d4 排成紧凑的四行控件，并实时显示棋盘预览；发送成功返回对局页。
   没有模型时自动建立无模型会话，编辑与复盘仍然可用。规则判断仍由会话负责。
6. 复盘先显示空棋盘与载入指引，载入后开放记录位置滑块与前后导航，实际棋步数单独显示。
   继续对局成功返回对局页；载入失败清除旧回放并禁用滑块，防止继续按钮误用上一份棋谱。
7. 自动执行使用单一流式事件；停止绕过 Gradio 队列。执行中禁用手动操作、连接身份与参数控件，
   空盘面或终局不能开始，终局自动停止。不增加 Timer 轮询。
8. 普通反馈使用 `role="status"`，错误使用 `role="alert"`，并出现在操作所在页面。
   方向键仅在对局页的空闲焦点下落子，输入、下拉、滑块、按钮及可编辑区域保留原生键盘操作；
   不接管组合键或持续按键重复事件。
   （2026-10-09 补充：分析与自动执行事件关闭 Gradio 全组件原生进度线；流式请求持续期间不再
   把绿色进度标记画在整组输入和输出上。状态栏和反馈区仍明确显示执行状态。）

## 取舍

- 保留 Gradio 5 原生控件，而不是引入另一套 SPA 与事件桥：会话边界和依赖保持一致，焦点与输入
  行为可沿用组件实现。棋盘和分析使用语义化 HTML，方便读坐标和比较结果。
- 使用一套完整纸面主题，包括系统暗色偏好下的控件色板，避免局部暗色输入与固定棋盘配色冲突。
- 控件最小宽度允许窄屏换行，不能用页面 `overflow-x: hidden` 掩盖真实的布局错误。

## 验证

- WSL `Ubuntu_22_04_Cuda`，项目现有 Python 环境、Gradio 5.50.0 和 C++ 扩展。
- WebUI 测试覆盖渲染、清单、真实会话的开局/分析/落子/保存/重放、回调输出数量、连接身份、
  运行停止状态、空盘面与终局、编辑预览、回放载入失败后的状态清除。
- 本机 Edge 无头浏览器连接 WSL 私有网卡上的临时预览，验证连接、开局、分析、自动执行与停止、
  保存、编辑预览与发送、复盘载入/前后导航/继续对局，跨页成功返回对局页。
- 360、390、768、1440px 下分别检查三个页面，页面滚动宽度等于视口宽度；分析表保留自己的滚动区。
  同时确认棋盘边界位于组件内，避免 Gradio 组件内部裁切掩盖布局错误。
  对实际截图做视觉核对，浏览器未报告 JavaScript 错误；方向键能落子，输入框焦点下不落子。
- `ruff check` 通过，WebUI 的 19 条测试通过。
- Gradio 5 提示 CSS/theme/js 在 6 中将迁移至 `launch()`；本项目依赖约束 `<6`，本次不升级框架。

启动复核：`make webui`；仅本机监听的默认行为仍由 ADR 0039 约束。临时私有网卡监听仅用于本次验收。
