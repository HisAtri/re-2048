# ADR 0046：数据集与模型默认归档在项目 output/

- 状态：已采纳
- 日期：2026-10-10

## 背景

Makefile 原先把输出根默认设为 `$HOME/r2048/output`，与源码仓库分离。数据集、训练运行和模型
因此需要额外记忆外部路径，也不便于从项目目录统一查看和归档。代码路径解析已经支持
`R2048_OUTPUT_DIR`，调整默认值不需要改变 C++/Python 的数据协议。

## 决策

1. Makefile 默认 `OUTPUT` 为仓库根目录的 `output/`，并继续导出为 `R2048_OUTPUT_DIR`。
2. 数据集、训练运行、模型、评测等产物继续使用既有子目录约定；用户可通过 `OUTPUT` 或
   `R2048_OUTPUT_DIR` 将输出重定向到其他磁盘。
3. 构建目录与 Python 虚拟环境仍默认置于 `$HOME/r2048/`，避免把编译和环境文件落到项目挂载盘。
4. 不自动搬动既有外部目录：归档需要保留原路径与产物身份，操作者确认内容后再迁移。

## 理由

项目内 `output/` 让数据集和模型位置直观、便于按项目管理，同时保留环境变量重定向能力。
仓库已忽略 `output/`，大型实验产物不会进入源码版本控制。构建与环境仍留在本地 ext4，
避免高频小文件写入带来的挂载盘开销。

## 验证方式

`make env-check` 应显示仓库根目录下的 `output/`；传入 `OUTPUT=/some/path` 时应显示并导出覆盖路径。
