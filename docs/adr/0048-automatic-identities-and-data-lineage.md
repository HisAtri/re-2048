# ADR 0048：自动身份分配、迭代发布与累计数据谱系

- 状态：已采纳
- 日期：2026-10-10

## 背景

任务、数据和训练 ID 曾分散依赖人工标签、秒级时间戳或配方字符串，无法保证并发唯一性。
ADR 0047 仅计本轮数据，继承训练时会将见过多轮数据的权重标为单轮规模。
现有 `source_key` 已提供与目录、批次名和续跑样本数无关的来源身份，直接复用即可去重。

## 决策

1. UTC 日期 + 三位流水号统一为 `YYYYMMDDNNN`。任务、数据、训练 run 和发布采用独立编号
   空间，001–999，用尽报错，已预留编号不回收。普通空间位于输出根，发布空间位于模型仓库根。
   Python/C++ 共用 `.identities/<空间>/lock` 和 `<YYYYMMDD>.counter`：`flock` 排他锁下读取
   十进制高水位，原子替换计数器。只锁发号过程，计算与多 worker 跑谱保持并行。显式发布号
   必须高于该日高水位；首次使用发布发号器时扫描旧清单接纳历史编号。
2. 默认任务名 `iter-YYYYMMDDNNN`，数据批名 `<策略>-s<模拟数>-YYYYMMDDNNN`；训练 run 保存
   `run_identity.json`，训练 checkpoint ID 为 `run-YYYYMMDDNNN-<阶段>`。配方仍保留在元数据，
   不承担唯一身份。显式任务/数据标签继续兼容，自动化默认省略它们；训练 output 也可省略。
3. 默认迭代顺序 `selfplay → train → publish → evaluate → rate`。`iterate --resume <目录>`
   从 `iteration.json` 恢复原配置，允许选择步骤和 force，不靠最近目录推断。任务级执行锁
   阻止同一目录的并发操作，不阻止独立任务。已有任务参数不同则要求新建任务。
4. `requests/<步骤>.json` 在执行前保存数据批、训练尝试与发布预留身份。完成后写步骤标记。
   训练恢复使用同一尝试目录和 last.pt；已完成数据批补回结果，不向完整批次追加。发布恢复
   同时核对预留源 checkpoint 摘要、发布文件 SHA256 和清单身份，再补步骤记录。
   force 使本步骤及下游请求/标记失效，新尝试分配新身份，保留旧训练文件和发布目录。
5. 完整模型评测使用发布 `.safetensor` 的 ID，价值诊断臂保留训练文件。CLI 最后一行优先返回
   本次发布模型路径，可直接传给下一轮 `--init-checkpoint`。
6. checkpoint、续跑文件、训练报告和发布清单携带 `data_lineage` v1：`complete`、`issues`、
   本轮 `current`、父模型来源并集 `inherited`、累计 `datasets`、直接父模型 `parent_models`。
   每个来源保存 `source_key`、关联 `batch_ids`、前缀覆盖数 `samples`。按 key 合并取最大
   覆盖数，批次 ID 仅展示；包含验证划分，不乘 epoch、采样权重或树内标签数量，零权重不计。
   仅权重初始化父模型参与继承，跑谱教师自身的数据不计入。两半合并同时合并来源与父模型。
7. 顶层记录 `current_dataset_samples`、`inherited_dataset_samples`、`dataset_samples`。
   前两者可重叠，累计数必须由来源并集计算。发布名 `sN` 与 manifest v2 的数据字段全部使用
   累计口径。v1 发布清单的旧规模是本轮规模，不能直接加到累计数；恢复时读 checkpoint 来源，
   不按标量或文件名推断。新完整谱系自包含，删除祖先文件不影响后续继承。
8. 历史恢复只循元数据、合并记录或匹配配置身份的训练报告提供的明确路径。父模型 ID 与已有
   SHA256 必须匹配；缺摘要不能只凭 ID 认定父模型。缺文件、身份冲突、循环或来源缺口记录为
   不完整。独立训练可携带缺口继续，正式发布拒绝；迭代在开始训练前检查父模型谱系完整性。
9. 发布仍逐张量校验无损转换；未训练头的 NaN 指标转换为 JSON null，使发布元数据符合 JSON
   标准并可准确比对。历史产物及评分记录不重写。

## 取舍

不累计“样本 × epoch”的训练曝光量；`sN` 表达来源覆盖量。当前 limit 是来源前缀，最大覆盖
数足以表达并集，未来若支持任意样本子集需升级谱系表示。高水位与预留请求避免重试发号和
同秒碰撞，崩溃可能留下空号，但不会把同一身份用于两份产物。当前文件锁协议面向 Linux/WSL。

## 验证

跨语言并发分配、停止批次恢复、重复来源/扩容/零权重/双父模型合并、历史补齐与摘要失败、
自包含谱系，以及两轮真实跑谱训练发布评测的集成用例；恢复已发布但未写标记的任务时复用
产物，重做上游时下游失效且旧发布仍保留。
