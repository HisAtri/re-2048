# ADR NNNN：标题

- 状态：提议 / 已采纳 / 已废弃（被 NNNN 取代）
- 日期：YYYY-MM-DD

## 背景

要解决的问题是什么，约束来自哪里（性能、可复现性、旧版教训、依赖现状）。

## 决策

具体决定了什么。写清楚到“照做时不需要再猜”的程度。

## 理由

为什么这样选。**必须包含被实测或结构性地否定的替代方案**——只写结论不写为什么，
下一个改动的人会重新踩同一遍。

## 替代方案

认真考虑过但没选的方案，以及它们各自哪里不合适。

## 验证方式

这条决策靠什么证据支撑：命令、测试、实测数字，或者“目前只是约定，尚无验证”。
不确定的地方要明写，不要伪装成已验证。
